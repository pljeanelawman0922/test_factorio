Version: 0.2.0
Date: 2026-10-04
  Features:
    - Any number of inputs and outputs from 1 to 16: counts without a hand-drawn design get a generated balancer (butterfly core, loop-backs for spare outputs, input merging when there are more inputs than outputs).
    - Routes use underground belts when plain belts can't get through (under other belts, rocks, water, cliffs).
    - Routes may turn an input end, an output start or a balancer port into an underground belt of the same direction.
    - Trees, rocks and cliffs (with cliff explosives) under the planned layout are marked for deconstruction; removing the planned balancer cancels the marks.
    - Belts lying completely inside the selection count as inputs / outputs too (even single belt pieces): a piece with more of the selected belts ahead of it than behind it is an input.
    - Compact 1 -> 3 splitter (4 x 6, three splitters, one of them sideways).
    - A balancer's input / output belt may be an existing belt end facing the same way (not rebuilt).
    - When the balancer doesn't fit, the message names the design size and a selection size that works.
    - Designs with unused inputs are avoided when a smaller one fits (2 belts -> 4 now builds 2 -> 4, not 4 -> 4).
    - A balancer output may go straight into an underground when something sits right in front of it (e.g. chests after the splitters).
    - Existing input / output belts are only replaced by undergrounds when nothing else works.
  Changes:
    - 4 -> 3 is now supported.

Version: 0.1.0
Date: 2026-10-04
  Features:
    - Selection tool that plans a belt balancer between input belt ends and output belt starts and places ghosts.
    - Designs for 1-4 inputs to 1-4 outputs (except 4 to 3) and a 1 to 1 lane balancer.
    - Belt routing around obstacles with negotiated-congestion A*.
    - Shift + drag removes planned ghosts; Shift + Alt + B removes the last planned balancer.
  Locale:
    - English and Russian.
